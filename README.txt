NEON RUNNER — FINGER SENSITIVITY UPDATE

HOW TO RUN
1. Extract this ZIP into a folder.
2. Double-click run.bat.
3. Click START GAME.
4. Click ENABLE CAMERA and allow camera permission.
5. Hold your hand where the camera can see it and move your index finger slightly left/right.

NEW: FINGER SENSITIVITY
Use the Finger sensitivity slider under the camera status.
- 2.4x is the default and lets you reach the sides with smaller finger movements.
- Increase it if you still need to move too far.
- Decrease it if the character moves too quickly or feels hard to control.

OTHER CONTROLS
- Mouse: move over the game area
- Keyboard: Left/Right arrows or A/D
- Touch: drag across the game area

NOTES
Camera tracking uses MediaPipe loaded from a CDN, so it requires internet access and camera permission. Mouse, keyboard, and touch controls do not require the camera.
